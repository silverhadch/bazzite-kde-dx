# Fedora's desktop platform layer, minus the desktop environment itself.
#
# Derived from the comps groups in workstation-product-environment, the same
# source Fedora's Atomic Desktops flatten into fedora-common-ostree-pkgs.yaml
# via comps-sync.py. Flattened and committed rather than resolved with
# 'dnf5 group install' for the same reason Fedora flattens it: group membership
# is not stable across releases (base-x was demoted from the environment's
# grouplist to its optionlist in F40), so resolving at build time silently
# changes what the image contains. An explicit list shows up in git diff.
#
# Refresh against a new release with libcomps:
#   dnf5 install -y python3-libcomps
#   python3 -c 'import libcomps,sys; c=libcomps.Comps(); c.fromxml_f(sys.argv[1]); \
#     [print(p.name) for g in ("hardware-support","networkmanager-submodules", \
#     "printing","input-methods","fonts") \
#     for p in c.groups_match(id=g)[0].packages \
#     if p.type in (libcomps.PACKAGE_TYPE_MANDATORY, libcomps.PACKAGE_TYPE_DEFAULT)]' \
#     /path/to/comps-rawhide.xml
#
# Anything self-built is blocked by the exclude drop-in, so entries here can
# never shadow the KDE tar.
